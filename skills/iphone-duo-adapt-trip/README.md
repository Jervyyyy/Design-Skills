# iphone-duo-adapt-trip

把 Trip 的直板机（普通 iPhone）Figma 设计稿，按《CT 折叠屏规范 · iPhone DUO AI Spec》适配成 iPhone DUO 三种形态的设计稿：

| 输出 | 尺寸 | 说明 |
|---|---|---|
| 01 outerPortrait 外屏 | 466 × 678 | 右侧 Vertical Bar 84，内容区 382 |
| 02 innerPortrait 内屏竖屏 | 669 × 951 | 右上 Reserved Region 151 × 84，内容撑满 |
| 03 innerLandscape 内屏横屏 | 951 × 669 | 右侧 Vertical Bar 84，可分栏（铰链在 476） |

规范来源：[CT折叠屏规范 · Spec for AI](https://www.figma.com/design/wOJ4et1R9Pez2LBXFZD5Af/CT%E6%8A%98%E5%8F%A0%E5%B1%8F%E8%A7%84%E8%8C%83?node-id=9739-24103)

## 怎么用

在接好 Figma 连接器的 Claude 里，发：

```
/iphone-duo-adapt-trip <直板机 frame 的 Figma 链接>
```

也可以直接说「把这个稿适配成 iPhone DUO」并附上链接。需要指定输出位置的话，再附一个 Section / Frame 链接，或者说明放在哪个页面的哪个位置。

### 流程

1. **分析直板机稿**：判断一级页 / 非一级页（有没有 TabBar）、卡片还是通栏布局、标题栏和底栏，找出可以改成多列的重复卡片。
2. **出方案示意图**：在直板机稿**下方**生成一张方案板。上排是**推荐方案**，下排是按开发难度降级的**备选方案**（通常是通栏适配）。每屏裁成一屏高，注明做法和开发成本。
3. **设计师确认**：可以全部选推荐、全部选备选，或每屏分别选。确认前不会出最终稿。
4. **生成适配稿**：整页高度的 01 / 02 / 03 三张稿，附一张「适配说明」卡（记录改了什么、需要人工检查什么）。默认放在直板机稿**右侧**空位，不会和已有内容重叠；也可以放进你指定的位置。

原稿不会被修改，所有改动都在复制出来的稿上做。

## 会自动处理的规则

- **标题栏**：换成 DUO 头部，总高 84（24 + 48 + 12），标题左对齐，左侧按钮距边等于页边距；原标题栏上的图标、隐藏的标题、透明背景等设置会保留。
- **安全区**：外屏和内屏横屏避让右侧 Vertical Bar，两种处理二选一且两屏保持一致——方式 B 内容避让、背景延伸；方式 A 整体避让、VB 区域置白。内屏竖屏避让右上角 Reserved Region。
- **页边距**：按窗口宽度断点取值（外屏 20，内屏竖屏卡片 24 / 通栏 32，内屏横屏卡片 32 / 通栏 40）。
- **多列网格**：重复卡片可改成 2 列或 3 列；卡片宽度小于 340 时，横向卡片里的图片改为 3:4（高度不变）。
- **分栏**（内屏横屏）：主内容 + 辅助信息（Main–Support），或列表 + 详情（List–Detail，需要提供详情页稿）。标题栏只覆盖主栏。
- **底栏**：贴底，宽度不进入 Vertical Bar；全局导航 TabBar 是系统控件，稿中只做示意。

## 需要人工处理的

- 浮层（Sheet）、底部提示条、对话框、视频、OCR、广告 Banner：不会自动改，会在方案说明里写清规范，需要手动调整。
- 要改成多列的卡片如果在组件实例内部，脚本改不了，会给出提示。
- 3:4 图片规则只自动处理「图在左、字在右」的横向卡片，纵向卡片会提示人工确认。
- Vertical Bar、竖向状态栏、铰链组件在库里没有发布：在规范文件里会复用页面上已有的组件，在业务文件里会画外观相近的矢量替身（图层名带「（复刻）」）。

## 安装

- **Claude Code**：把本文件夹复制到 `~/.claude/skills/iphone-duo-adapt-trip/`（本机所有项目可用），或复制到某个项目的 `.claude/skills/` 下。
- **claude.ai**：把本文件夹打包成 zip，在 Skills 设置里上传。

使用前需要连接 Figma 连接器（MCP），并对设计稿所在文件有编辑权限。

## 文件说明

| 文件 | 作用 |
|---|---|
| `SKILL.md` | 给 Claude 读的完整流程、参数说明和注意事项 |
| `reference/duo-rules.md` | DUO 规范摘录 + 推荐 / 备选方案决策表 |
| `scripts/analyze.js` | 分析直板机稿（只读） |
| `scripts/generate.js` | 生成方案示意图（proposal）或最终适配稿（final） |
| `scripts/check.mjs` | 修改脚本后的本地语法检查：在本文件夹下运行 `node scripts/check.mjs` |
